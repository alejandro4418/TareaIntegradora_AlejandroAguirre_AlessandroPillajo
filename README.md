## Descripción del proyecto
Este repositorio contiene el desarrollo de la Tarea Integradora de la asignatura **Programación Orientada a Objetos**, elaborada en lenguaje Java.
El proyecto tiene como finalidad aplicar conceptos fundamentales de Programación Orientada a Objetos mediante la resolución de ejercicios prácticos enfocados en el uso de clases, objetos, encapsulamiento, herencia, polimorfismo, validaciones y organización modular del código.
# Ejercicios desarrollados
## Ejercicio 1: Sistema de Subsidio de Gasolina
Sistema que permite registrar solicitantes y verificar si cumplen con los requisitos establecidos para recibir el subsidio de gasolina en Ecuador.
### Funcionalidades implementadas:
- Registro de datos del solicitante
- Validación de ingresos mensuales
- Validación de cantidad de vehículos
- Verificación de residencia en Ecuador
- Evaluación automática de aprobación o rechazo
- Mensajes de resultado
- Método `mostrarToString()`
- Método estático informativo
- Sobrecarga de métodos para consumo mensual
## Ejercicio 2: Sistema Bancario
Sistema orientado a objetos para administrar distintos tipos de cuentas bancarias y calcular automáticamente los intereses mensuales.
### Tipos de cuentas:
- Cuenta de Ahorros
- Cuenta Corriente
- Cuenta de Inversión
### Funcionalidades implementadas:
- Clase abstracta base
- Encapsulamiento de atributos
- Herencia
- Polimorfismo
- Validaciones bancarias
- Cálculo de intereses
- Reporte general del banco
